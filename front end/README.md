# Fund For Future frontend

Next.js implementation of the reference in `../image.png`.

Run from this directory:

```powershell
npm install
npm run dev
```

Open http://localhost:3000. Run `npm run build` for production compilation.

Student profile submissions save locally on this device. Authentication, password reset, and scholarship discovery are demo interfaces awaiting a backend. Passwords are never stored or submitted. The campus photo loads from Unsplash and requires internet access.
